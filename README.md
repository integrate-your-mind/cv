# Romy Mondello — portfolio

Static, accessible GitHub Pages portfolio for Romy Mondello, senior AI and systems engineer, founder, and independent researcher.

The site is intentionally plain HTML and CSS so it can be reviewed and hosted directly from GitHub Pages. It brings together Romy’s engineering, founder, and research work in one readable profile.

## Local review

Open `index.html` directly in a browser or serve this directory with any static file server. The only local asset is `assets/romy-professional-headshot.png`.
